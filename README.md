# Readme

This project includes static html pages with content for some recipes for practicing writing html markup. This is a very basic project to showcase skills and understanding in building a basic static html page, using semantic html markup.
The project requirements and tasks to complete and knowledge to demonstrate all comes from the odin project, and can be reviewed from their HTML foundations > Recipes project page.


## Goals
- Demonstrate understanding of how to build a static html webpage
- Demonstrate knowledge of HTML and how to build a HTML structured content
- Demonstrate HTML boilerplate practices (use of HTML5 doctype boilerplate)


## Accomplishments
- [x] Building static html site that is hostable
- [x] Building a multipage html site with semantic anchors to other pages
- [x] Using semantic markup and structure to showcase content, sans CSS in a clear, readable fashion for reader
- [x] Satisfy project requirements given.
